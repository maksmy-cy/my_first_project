1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?
Основное свойство — display: flex (или display: inline-flex). После его применения элемент становится flex-контейнером, а все его прямые дочерние элементы — flex-элементами. Они выстраиваются вдоль главной оси (по умолчанию — горизонтально), получают возможность гибко менять размеры, выравниваться и распределяться по контейнеру.

2. В чем разница между justify-content и align-items?
justify-content — выравнивает flex-элементы вдоль главной оси (main axis). Пример: justify-content: space-between; — равномерно распределяет элементы по горизонтали.

align-items — выравнивает элементы вдоль поперечной оси (cross axis). Пример: align-items: center; — центрирует элементы по вертикали.

Пример использования вместе:

css
.container {
  display: flex;
  justify-content: center; /* по горизонтали */
  align-items: center;     /* по вертикали */
}
3. Что делает свойство flex-direction и какие значения может принимать?
flex-direction задаёт направление главной оси и порядок следования элементов. Значения:

row (по умолчанию) — слева направо;

row-reverse — справа налево;

column — сверху вниз;

column-reverse — снизу вверх.

Оно определяет, какая ось будет главной, а какая — поперечной, и как будут выстраиваться элементы.

4. Объясните значение трех свойств в сокращенной записи flex: 1.
flex: 1 — это сокращение для:

flex-grow: 1 — элемент может растягиваться, занимая свободное пространство;

flex-shrink: 1 — элемент может сжиматься при нехватке места;

flex-basis: 0% — базовая ширина элемента равна 0 (он растёт от нуля).

Итог: все элементы с flex: 1 делят доступное пространство поровну.

5. Как работает свойство flex-wrap и в каких случаях его следует использовать?
flex-wrap управляет переносом flex-элементов на новую строку:

nowrap (по умолчанию) — все элементы в одну линию;

wrap — перенос на новую строку при нехватке места;

wrap-reverse — перенос в обратном порядке.

Используется, когда элементов много и они не должны сжиматься до нечитаемого состояния (например, галереи, карточки, меню).

6. Чем отличается align-content от align-items?
align-items выравнивает элементы внутри одной линии вдоль поперечной оси.

align-content выравнивает сами линии (ряды) относительно контейнера. Работает только при flex-wrap: wrap и наличии нескольких строк.

Пример: при трёх строках карточек align-content: space-between распределит строки по высоте контейнера.

7. Как свойство order влияет на отображение элементов и в каких ситуациях полезно?
order меняет порядок отображения flex-элементов без изменения HTML. По умолчанию order: 0; чем больше значение — тем позже элемент.

Полезно для:

изменения порядка блоков на мобильных устройствах;

вывода важного контента вперёд;

визуальной перестановки без правки разметки.

8. Что такое «осевая линия» (main axis) и поперечная ось (cross axis) в Flexbox?
Главная ось (main axis) — направление, вдоль которого выстраиваются flex-элементы. Задаётся flex-direction.

Поперечная ось (cross axis) — перпендикулярна главной.

Если flex-direction: row, главная ось — горизонтальная, поперечная — вертикальная. Если column — наоборот.

9. Как создать адаптивный макет с помощью Flexbox без медиа-запросов?
Использовать flex-wrap: wrap и гибкие значения flex. Пример:

css
.container {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.card {
  flex: 1 1 250px; /* минимум 250px, растягивается */
}
Карточки автоматически переносятся на новую строку при сужении экрана.

10. Какие преимущества даёт gap вместо margin для промежутков между flex-элементами?
Не создаёт лишних отступов по краям контейнера.

Работает и по главной, и по поперечной оси.

Не требует «хаков» с :last-child или отрицательными margin.

Код чище и предсказуемее.

Поддерживается всеми современными браузерами.
