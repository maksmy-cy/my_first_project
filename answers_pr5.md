# Ответы на вопросы для самоконтроля

## 1. Какое основное свойство включает CSS Grid и чем принципиально отличается от Flexbox?

Основное свойство — `display: grid`. CSS Grid — это **двумерная** система компоновки, которая позволяет одновременно управлять строками и столбцами. Flexbox — **одномерная** система (работает либо по строке, либо по столбцу). Grid лучше подходит для создания сложных макетов страниц, а Flexbox — для выравнивания элементов внутри компонентов.

## 2. В чем разница между `grid-template-columns` и `grid-auto-columns`?

- `grid-template-columns` — задаёт **явные** столбцы сетки (те, что описаны в шаблоне).
- `grid-auto-columns` — задаёт размер **неявных** столбцов, которые создаются автоматически, когда элементы выходят за пределы явной сетки.

`grid-template-columns` используется для основного макета, а `grid-auto-columns` — для управления дополнительными элементами.

## 3. Что делают функции `repeat()`, `minmax()` и `auto-fit`?

- `repeat(n, size)` — повторяет определение столбца/строки `n` раз. Пример: `repeat(3, 1fr)`.
- `minmax(min, max)` — задаёт минимальный и максимальный размер. Пример: `minmax(200px, 1fr)`.
- `auto-fit` — автоматически подстраивает количество колонок под ширину контейнера, растягивая их. Пример: `repeat(auto-fit, minmax(200px, 1fr))`.

## 4. Как работают именованные grid-области и какие преимущества они дают?

Именованные области задаются через `grid-template-areas` в виде строк с именами. Элементы привязываются через `grid-area: name`. Преимущества: наглядность, удобство изменения макета, лёгкость адаптации под мобильные устройства.

## 5. Объясните систему нумерации grid-линий и как с помощью `grid-column` и `grid-row` размещать элементы.

Линии нумеруются начиная с 1. `grid-column: 1 / 3` означает: начать с линии 1 и закончить на линии 3 (занять 2 колонки). Аналогично `grid-row`. Можно использовать `span`: `grid-column: span 2`.

## 6. Что такое `grid-gap` (или `gap`) и чем он лучше margins?

`gap` задаёт промежутки между строками и столбцами сетки. Преимущество: не нужно добавлять margins к каждому элементу, промежутки не влияют на внешние границы контейнера, работают равномерно.

## 7. Как свойства `justify-items` и `align-items` влияют на выравнивание grid-элементов?

- `justify-items` — выравнивает элементы по **горизонтали** внутри своих ячеек.
- `align-items` — выравнивает элементы по **вертикали**.

Значения: `start`, `end`, `center`, `stretch`.

## 8. В чем разница между `auto-fill` и `auto-fit`?

- `auto-fill` — создаёт столько колонок, сколько помещается, даже если они пустые.
- `auto-fit` — создаёт колонки, но **схлопывает** пустые, растягивая существующие элементы.

`auto-fit` чаще используется для адаптивных галерей.
