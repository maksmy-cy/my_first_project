1. Что такое Viewport meta tag и почему он важен?
<meta name="viewport" content="width=device-width, initial-scale=1.0"> сообщает браузеру, что ширина страницы равна ширине экрана устройства, а масштаб — 1:1. Без него мобильные браузеры отображают страницу как «уменьшенную» десктопную версию (виртуальный viewport ~980px), что делает текст нечитаемым, а элементы — слишком мелкими.

2. Какие подходы к адаптивным макетам использовались?
Fluid — «резиновые» блоки через %, max-width, flex, grid (контейнер, сетка преимуществ).

Adaptive — переключение макетов под фиксированные диапазоны через @media (2 колонки → 1 колонка).

Responsive — сочетание fluid + adaptive + адаптивная типографика (clamp()) и медиа-запросов.

3. Mobile First vs Desktop First
Mobile First — базовые стили пишутся для мобильных, а через min-width добавляются стили для больших экранов. Преимущества: меньший объём CSS для мобильных, проще наращивать функциональность, соответствует современным приоритетам трафика. Desktop First (использован в ПР) — базовые стили для десктопа, max-width ограничивает. Минус — мобильные стили «переопределяют» десктопные, что может давать конфликты.

4. Предпочтительные единицы измерения
rem — для шрифтов и отступов (зависит от html { font-size }, легко масштабируется).

% — для ширин и «резиновых» контейнеров.

vw/vh — для секций во всю высоту/ширину экрана.

em — для локальных отступов внутри компонента.

px — только для границ и мелких фиксированных деталей.

5. Как clamp() помогает в адаптивной типографике?
clamp(min, preferred, max) задаёт размер шрифта, который плавно меняется между минимумом и максимумом в зависимости от viewport. Например: font-size: clamp(1.5rem, 5vw, 2.5rem) — на телефоне ~1.5rem, на десктопе ~2.5rem, без «скачков» на брейкпоинтах.

6. Основные брейкпоинты и их определение
1200px+ — десктоп (3 колонки преимуществ, контент + сайдбар).

768–1024px — планшет (2 колонки преимуществ, сайдбар вниз).

480–768px — мобильные (бургер-меню, 2 колонки → 1).

<480px — маленькие мобильные (1 колонка, уменьшенные отступы).

Значения выбраны по типичным разрешениям устройств (iPhone, iPad, ноутбуки) и по моменту, когда контент начинает «ломаться».

7. Как @media создаёт адаптивные стили?
Медиа-запрос применяет CSS только при выполнении условия:

css
@media (max-width: 768px) {
  .nav-menu { display: none; }
  .nav-menu.active { display: flex; }
}
Здесь при ширине ≤768px меню скрывается и показывается только при добавлении класса .active.

8. max-width vs min-width
max-width — стили применяются для экранов уже указанного (Desktop First). Пример: @media (max-width: 768px).

min-width — стили для экранов шире указанного (Mobile First). Пример: @media (min-width: 768px).
Использовать min-width предпочтительнее для Mobile First, max-width — для Desktop First.

9. Адаптивные изображения
css
img {
  max-width: 100%;
  height: auto;
  display: block;
}
Дополнительно: srcset и sizes для выбора оптимального файла, <picture> для арт-дирекшена, object-fit: cover для сохранения пропорций.

10. Инструменты браузера для тестирования
DevTools → Device Toolbar (Ctrl+Shift+M) — эмуляция устройств.

Responsive Design Mode в Firefox.

Lighthouse — аудит производительности и адаптивности.

Проверка на реальных устройствах через локальную сеть.

Расширения: Responsive Viewer, Window Resizer.
