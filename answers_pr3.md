1. В чём разница между селектором по классу и по ID?
Параметр	Класс .name	ID #name
Специфичность	0,1,0	1,0,0
Повторное использование	Можно на многих элементах	Должен быть уникален на странице
Множественное применение	<div class="a b">	Только один id на элемент
Применение	Стилизация групп	Уникальные «якоря», JS-хуки
Вывод: классы удобнее для массовой стилизации, ID — для уникальных элементов и высокой специфичности.

2. Как работает каскад в CSS?
Каскад — алгоритм разрешения конфликтов между правилами. Порядок приоритетов (от высшего к низшему):

!important пользователя

!important автора

Обычные стили автора

Стили пользователя

Стили браузера (user-agent)

При равном происхождении — сравнивается специфичность, а при равной специфичности — порядок объявления (побеждает последнее).

4. Наследуемые и ненаследуемые свойства
Наследуются по умолчанию:

color

font-family

font-size

line-height

text-align

visibility

Не наследуются:

margin

padding

border

background

width / height

display

5. > vs пробел
.content > article — дочерний: выбирает только прямых детей.

.content article — потомок: выбирает всех потомков на любой глубине.

Пример:

html
<div class="content">
  <article>...</article>          <!-- попадёт под оба -->
  <section><article>...</article></section> <!-- только под потомка -->
</div>
6. Псевдоклассы :hover и :nth-child()
:hover — реакция на наведение курсора (кнопки, ссылки, карточки, подсветка строк таблицы).

:nth-child() — выбор по позиции среди сиблингов: «зебра» в таблицах, чередование цветов, скрытие элементов, оформление каждого N-го блока.

7. Что делает !important и почему опасен?
Правило !important переопределяет все прочие объявления того же свойства независимо от специфичности.

Использовать осторожно, потому что:

ломает естественный каскад и наследование;

усложняет отладку (непонятно, почему стиль не применяется);

провоцирует «войну !important»;

ухудшает поддержку темы и адаптивность.

Применяют только для крайних случаев: переопределение сторонних библиотек, служебные утилиты.

8. Псевдоэлементы ::before и ::after
Позволяют вставить виртуальный контент до/после содержимого элемента без правки HTML. Обязательно свойство content.

Могут содержать:

текст (content: "★");

Unicode-символы;

изображения (content: url(...));

значения счётчиков (counter());

пустую строку (content: "") — для декора.

Примеры: иконки, кавычки, буллиты, декоративные линии, бейджи «new».

9. Порядок при равной специфичности
Применяется правило, объявленное позже в CSS (с учётом порядка подключения файлов и порядка правил внутри файла). Также учитывается происхождение стилей и наличие !important.

10. Инструменты разработчика в браузере
Elements / Inspector — просмотр применённых стилей, вычисленных значений, наследования.

Показывают, какое правило победило и какое зачёркнуто.

Позволяют включать/отключать свойства, менять значения в реальном времени.

Показывают блочную модель (margin, padding, border).

Вкладка Computed — итоговые значения.

Coverage — неиспользуемый CSS.

Performance / Rendering — влияние стилей на отрисовку.
